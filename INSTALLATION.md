# Install
Requires GTA SA **1.0 US** (32-bit) + an ASI loader (e.g. Silent's ASI Loader / Ultimate ASI Loader).
Copy `NITRO_FX.asi` into the GTA SA folder (next to gta_sa.exe). Start the game, sit in a car, hold **R + S + I**.
`NITRO_FX\` data folders (vehicles, saves) are created next to the .asi on first run. Old saves/profiles keep working.
Saves tab: "Save Current As..." -> type a name -> SAVE. Load / Overwrite / Delete per row. Saves of other vehicle models are
listed with "Show all vehicles" but refuse to load on a different model.
